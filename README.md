# 🏋️ GYMVex

> **Train. Track. Transform.**

GYMVex is a modern **Gym & Fitness mobile application** built with React Native.
It helps users discover exercises, follow workout plans, track calories, and monitor their fitness progress.

## ✨ Features

- 🔐 User Authentication
- 👤 Personal Fitness Profile
- 🏋️ Exercise Database
- 📋 Workout Plans
- 💪 Beginner, Intermediate & Advanced Workouts
- ⏱️ Workout & Rest Timer
- 🔥 Calories Tracking
- 📊 Progress Tracking
- 🧘 Yoga & Flexibility
- 🌙 Dark & Light Mode
- 📱 Responsive Mobile UI

## 🛠️ Technologies

**Frontend**
- React Native
- Expo
- Expo Router

**Backend**
- Node.js
- Express.js
- MongoDB
- Mongoose
- REST API

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/YOUR_USERNAME/GYMVex.git
cd GYMVex
```

### 2. Install dependencies

```bash
npm install
```

### 3. Start the app

```bash
npx expo start
```

## 🔧 Backend Setup

```bash
cd backend
npm install
npm run dev
```

Create a `.env` file inside the `backend` folder:

```env
PORT=5000
MONGO_URI=your_mongodb_connection_string
```
